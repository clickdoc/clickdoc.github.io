Clickdoc

Clickdoc for IT

Updated 8 October 2026. For the person asked to approve Clickdoc.

Clickdoc is a Chrome extension that records clicks into a step-by-step guide with screenshots. It has no server, no account and no AI. Guides and screenshots stay in the browser's local storage on the machine that made them. This page lists what it can access, every network request it can make, and how to deploy it.

Permissions, and what each is used for

PermissionWhy
<all_urls> (host access)To take a screenshot of the visible tab at each step, and to run the step recorder on whatever site is being documented. A small script is present on pages, but it sends nothing unless the user has pressed record.
tabsTo take the screenshot of the visible tab and read its title and address for the step.
webNavigationTo record a "go to this page" step when the recorded tab moves to a new page.
storage, unlimitedStorageTo keep guides, with their screenshots, in the browser's local extension storage. Screenshots exceed the default quota.

It does not ask for cookies, history, downloads, clipboard reading, identity or native messaging permissions.

To check this yourself: open chrome://extensions, turn on Developer mode, click "service worker" under Clickdoc, and watch the Network tab while recording and exporting a guide. Page requests you see belong to the website being recorded, not to Clickdoc.

What it records, and what it hides

  • Only between Start and Stop, which the user presses. Nothing is recorded otherwise.
  • Each step holds a screenshot of the visible tab, a line of text describing the action, the page title and address.
  • Password fields, and fields named or marked as card numbers, security codes, tokens and similar secrets, are written as dots in the step text and drawn as dots on screen while recording, so screenshots do not show them.
  • Email addresses, card numbers, IBANs, US social security numbers and phone numbers shown anywhere on the page are covered with a grey bar while recording and written as dots in the step text. The page itself is not changed: the cover is painted on top. The user can switch this off per recording.
  • Anything else can be blurred by the user before exporting. The blur is baked into the image, and the unblurred original is not included in any export.

Where data lives

In chrome.storage.local for the extension, on that machine and browser profile only. It is not synced. Removing the extension deletes it. A guide leaves the machine only when the user exports it to a file or copies it, and then only to where the user puts it.
